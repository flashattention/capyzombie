# 플레이스토어 등록 자료

Play Console → **스토어 등록정보** → 기본 스토어 등록정보(한국어), 그리고 "번역 관리"로 언어(영어, 일본어, 중국어 간체)를 추가해 언어마다 아래 파일을 넣는다.

| Play Console 항목 | 파일 | 규격 |
|---|---|---|
| 앱 이름 · 간단한 설명 · 자세한 설명 | `<언어>/listing.txt` | 30자 · 80자 · 4000자 이내 (확인함) |
| 앱 아이콘 | `icon-512.png` (모든 언어 공통) | 512×512 PNG |
| 그래픽 이미지 | `<언어>/feature-graphic-1024x500.png` | 1024×500, 투명도 없음 |
| 휴대전화 스크린샷 | `<언어>/screenshot-1…5-*.png` | 1920×1080(16:9), 투명도 없음, 2~8장 |

언어 폴더: `ko`(한국어), `en`(영어 – 미국 en-US), `ja`(일본어), `zh-CN`(중국어 – 간체 zh-CN)

- 스크린샷은 실제 게임 화면(휴대폰 가로 화면, 터치 조작)이다. 업적 화면은 진행도가 쌓인 예시 상태로 찍었다.
- 원본 텍스트는 `listing.json`. 문구를 고치면 `listing.txt`도 같이 고친다.
