# 카피좀비

세상 느긋한 카피바라 등에 올라탄 작은 동물이 되어, 1인칭으로 게틀링건과 로켓을 쏘며 몰려드는 좀비 떼를 물리치는 3D 웹 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

> 현재 프로토타입 단계입니다. 아래 "아직 없는 것"을 참고하세요.

## 플레이 방법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 (시선 기준) |
| 마우스 | 조준 |
| 좌클릭 | 게틀링건 연사 |
| 우클릭 (또는 `Shift`) | 돌진. 스태미나를 쓰며 좀비를 들이받아 날려 버립니다 |
| `Q` | 로켓 포드 |
| `E` | 발 구르기. 주변 좀비를 날려 버립니다 |
| `R` | 궁극기 귤 폭격. 좀비 40마리를 처치하면 충전됩니다 |
| `Space` | 점프. 제트팩을 얻은 뒤에는 공중에서 누르고 있으면 날아오릅니다 |
| `V` | 1인칭 ↔ 3인칭 전환 |
| `1` `2` `3` | 레벨업 강화 선택 |
| `Esc` | 일시정지 메뉴 (계속하기, 처음부터 다시, 캐릭터 선택, 메인으로) |

화면을 클릭하면 마우스가 잠기고 조준이 시작됩니다. 터치 기기에서는 화면 왼쪽을 끌어 이동하고 오른쪽을 끌어 조준·사격하지만, 돌진 버튼과 Q·E·R 스킬 버튼은 아직 없습니다.

## 게임 구성

- **캐릭터 선택**: 라이더 동물 5종(오리, 개구리, 고양이, 강아지, 햄스터)을 고르고, 모자·얼굴·목 악세사리로 꾸미고, 이름을 지어 줍니다. 마우스 감도와 효과음도 여기서 설정합니다.
- **웨이브와 보스**: 1분마다 그 전장 탱커의 거대 버전이 보스로 나옵니다. 보스 셋을 잡으면 클리어이고, 무한 모드로 계속할 수도 있습니다.
- **전장 4곳**: 앞 전장을 클리어하면 다음 전장이 열립니다. 맵마다 지형지물과 좀비 4종이 다릅니다.

  | 전장 | 지형지물 | 기본 | 러너 | 탱커 | 폭탄 |
  |---|---|---|---|---|---|
  | 유자 농장 | 헛간, 풍차, 밭, 연못 | 농부 좀비 | 꼬마 좀비 | 호박머리 | 농약통 좀비 |
  | 네온 도심 | 도로망, 빌딩, 자동차 | 회사원 좀비 | 배달 러너 | 공사장 반장 | 가스통 좀비 |
  | 사막 유적 | 계단식 피라미드, 돌 아치, 오아시스 | 미라 좀비 | 카우보이 좀비 | 선인장 좀비 | 다이너마이트 좀비 |
  | 캔디 놀이공원 | 케이크 탑, 대관람차, 초콜릿 강 | 파티모자 좀비 | 토끼 머리띠 | 풍선껌 뚱보 | 팝핑캔디 좀비 |

- **레벨업**: 좀비가 떨어뜨린 귤을 모으면 레벨이 오르고, 강화 카드 3장 중 하나를 고릅니다.
- **후반 장비**: 클리어한 전장 수에 따라 레벨업 카드에 레이저(1곳), 제트팩(2곳), 강화 수트(3곳)가 등장합니다.
- **연속 처치**: 3초 안에 계속 처치하면 콤보가 쌓이고, 25마다 체력을 채우는 붉은 귤이 떨어집니다.
- **폭탄 좀비**: 죽으면 터져 주변 좀비를 휩씁니다. 가까이서 터지면 플레이어도 다칩니다.
- **레이더와 기록**: 화면 우상단 레이더가 주변 좀비를 보여 주고, 전장별 최고 기록이 저장됩니다.

기획 의도와 수치는 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)에 있습니다.

## 개발

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (기본 http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm run preview  # 빌드 결과 미리 보기
```

- `/` 는 랜딩페이지, `/play.html` 이 게임입니다.
- 개발용 주소 (화면 확인과 회귀 점검용)
  - `/play.html?unlock` 전장과 후반 장비를 모두 연 상태
  - `/play.html?unlock&map=city` 전장 지정 (`farm`, `city`, `desert`, `candy`)
  - `/play.html#play` 선택창 건너뛰기
  - `/play.html#sim90` 자동 조준·연사로 90초를 미리 진행 (숫자 생략 시 20초). 결과가 문서 제목에 JSON으로 남습니다
  - `/play.html#retry` 재시작 뒤에도 UI가 남는지 점검

### 배포

`main` 브랜치에 푸시하면 Vercel이 자동으로 빌드해 배포합니다. Vite 프리셋 기본값(빌드 `npm run build`, 출력 `dist`)을 그대로 씁니다.

## 코드 구조

```
index.html            랜딩페이지
play.html             게임 (선택창, HUD, 레벨업 화면의 DOM)
src/
  main.js             게임 진입점. 선택창 ↔ 전장 전환, 프레임 루프
  select.js           캐릭터 선택창
  game.js             전장: 입력, 이동·돌진·점프, 좀비 떼와 보스, 무기, 레벨업, HUD
  world.js            전장 만들기: 지형지물, 고지대, 소품, 하늘과 원경, 충돌 상자
  audio.js            효과음 (Web Audio 합성, 외부 파일 없음)
  upgrades.js         전투 수치와 레벨업 강화 목록
  maps.js             전장 4곳의 색·소품·지형지물·좀비 정의
  save.js             프로필, 진행도(클리어·기록), 설정 저장 (localStorage)
  kit.js              로우폴리 조립 키트, 조명, 모델 굽기(bake)
  models/
    capy.js           카피바라와 등에 실린 무기
    riders.js         라이더 동물 5종과 악세사리
    zombies.js        좀비 조립 (맵별 장식 포함)
  landing.js/.css     랜딩페이지의 3D 미리보기와 스타일
  style.css           게임 UI 스타일
docs/
  GAME_DESIGN.md      재미·완성도 기획서와 구현 상태
concepts/
  style-sheet.html    초기 그래픽 시안 4종 (A 로우폴리를 채택)
```

### 그래픽 방식

채택한 양식은 **로우폴리 플랫 셰이딩**입니다. 텍스처와 외부 모델 파일 없이, `kit.js`의 구·상자·원기둥·원뿔 프리미티브에 단색 머티리얼을 입혀 코드로 조립합니다.

좀비 떼는 수백 마리를 그려야 하므로, 조립한 좀비 모델을 정점 색을 가진 지오메트리 하나로 굽고(`bake`) 종류마다 `InstancedMesh` 하나로 그립니다. 맵 소품과 고지대도 한 덩어리로 구워 드로우콜 한 번에 그립니다.

### 내용 추가하기

- **강화 추가**: `src/upgrades.js`의 `UPGRADES`에 항목을 추가합니다. `available(ctx)` 함수를 달면 해금 조건을 걸 수 있습니다 (`ctx.cleared`는 클리어한 전장 수).
- **전장 추가**: `src/maps.js`의 `MAPS`에 색, 소품 목록, 좀비 4종, 지형지물을 놓는 `build()`를 추가합니다. 새 좀비 장식은 `src/models/zombies.js`의 `acc` 분기에 추가합니다.
- **라이더·악세사리 추가**: `src/models/riders.js`의 `RIDERS`, `HATS`, `FACES`, `NECKS`에 추가하면 선택창에 자동으로 나타납니다.

## 아직 없는 것

- 배경 음악
- 메타 성장(영구 강화, 도전 과제), 협동 멀티플레이
- 데스크톱 빌드와 스팀 연동, 게임패드 지원
- 터치 기기용 돌진·스킬 버튼
- 난이도와 수치 밸런스 조정 (자동 진행으로만 점검했고, 사람 손으로 한 플레이테스트는 아직 부족합니다)
