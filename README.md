# 카피좀비

세상 느긋한 카피바라 등에 올라탄 작은 동물이 되어, 1인칭으로 게틀링건과 로켓을 쏘며 몰려드는 좀비 떼를 물리치는 3D 웹 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

> 현재 프로토타입 단계입니다. 아래 "아직 없는 것"을 참고하세요.

## 플레이 방법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 (시선 기준) |
| 마우스 | 조준 |
| 좌클릭 | 게틀링건 연사 (카피바라 왼쪽) |
| 우클릭 | 로켓 포드 (카피바라 오른쪽) |
| `Shift` + `W` | 돌진. 스태미나를 쓰며 좀비를 들이받아 날려 버립니다 |
| `Q` | 발 구르기. 주변 좀비를 날려 버립니다 |
| `E` | 미끼 귤. 조준한 곳에 던져 좀비를 꾀어낸 뒤 터뜨립니다 |
| `R` | 궁극기 귤 폭격. 좀비 40마리를 처치하면 충전됩니다 |
| `Space` | 점프. 제트팩을 얻은 뒤에는 공중에서 누르고 있으면 날아오릅니다 |
| `V` | 1인칭 ↔ 3인칭 전환 |
| `1` `2` `3` | 레벨업 강화 선택 |
| `Esc` | 일시정지 메뉴 (계속하기, 처음부터 다시, 캐릭터 선택, 메인으로) |

처음 시작할 때 닉네임(2~12자)을 반드시 정해야 합니다. 닉네임은 계정에 저장되어 캐릭터를 바꿔도 그대로이고 전체 랭킹에 표시됩니다.

터치 기기에서는 화면 왼쪽을 끌어 이동하고 오른쪽을 끌어 조준·사격하지만, 로켓과 Q·E·R 스킬 버튼은 아직 없습니다.

## 게임 구성

- **라이더 8종과 특성**: 오리(연사 +10%), 개구리(점프 +25%), 고양이(치명타 +10%), 강아지(귤 끌어오기 +40%), 햄스터(스태미나 회복 +30%), 토끼(이동 +10%), 펭귄(발 구르기 대기 −30%), 너구리(경험치 +15%). 모자 12종, 얼굴 6종, 목 6종으로 꾸밉니다.
- **전장 6곳**: 앞 전장을 클리어하면 다음 전장이 열립니다. 뒤로 갈수록 가파르게 어려워집니다(전장마다 좀비 체력 ×1.32, 공격력 ×1.15, 수 +12%). 대신 뒤 전장은 강화 카드를 전장 순번 × 3장 미리 뽑고 시작합니다.

  | 전장 | 지형지물 | 1웨이브 보스 (패턴) |
  |---|---|---|
  | 유자 농장 | 헛간, 도는 풍차, 밭, 과수원, 트랙터 | 호박 대왕 (부하 소환) |
  | 네온 도심 | 도로망과 횡단보도, 빌딩, 공원, 자동차와 버스 | 현장 소장 (충격파) |
  | 사막 유적 | 계단식 피라미드, 사자 석상, 오아시스, 야영지 | 선인장 군주 (가시 난사) |
  | 캔디 놀이공원 | 케이크 탑, 도는 대관람차와 회전목마, 초콜릿 강 | 풍선껌 여왕 (폭탄 좀비 투하) |
  | 눈꽃 온천 | 체력이 차는 노천탕, 온천 여관, 붉은 문, 얼어붙은 호수 | 눈사람 장군 (눈덩이 난사) |
  | 달빛 묘지 | 예배당, 계단식 납골당, 묘비 밭, 고목 (밤) | 프랑켄 박사 (충격파) |

- **좀비 12유형 × 전장 6곳 = 72종**: 기본, 러너, 탱커, 폭탄(죽으면 폭발), 원거리(침을 뱉음), 도약(뛰어올라 덮침), 방패(치명타가 아니면 탄 피해 30%), 치유(주변 좀비 회복), 분열(죽으면 떼거리 셋), 돌격(달아오른 뒤 일직선 돌진), 떼(다섯 마리씩), 맹독(독 웅덩이). 금빛 정예는 체력이 4배입니다.
- **보스 18종**: 전장마다 셋이 차례로 나옵니다. 1웨이브는 근접형, 2웨이브는 거리를 두고 저격·포격·탄막을 쓰는 **원거리 보스**, 3웨이브는 여러 패턴을 섞는 복합형입니다. 체력이 절반 아래면 패턴을 더 자주 씁니다.
- **웨이브와 보스**: 1분마다 보스가 나오고 셋을 잡으면 클리어입니다. 이후 무한 모드로 계속할 수 있습니다.
- **레벨업 강화 28종과 합성 12종**: 두 강화를 일정 레벨까지 키우면 합성 카드가 나옵니다(예: 연사 속도 3 + 급소 사격 2 → 폭풍 게틀링). 카드에 합성 조합이 표시되고, 일시정지 화면에서 현재 빌드와 진행 중인 합성을 봅니다. 카드가 마음에 안 들면 다시 뽑기(기본 2회, 보스 처치마다 +1)를 씁니다.
- **후반 장비**: 클리어한 전장 수에 따라 레이저(1곳), 제트팩(2곳), 강화 수트(3곳)가 카드에 등장합니다.
- **맵 요소**: 점프대(밟으면 높이 튀어 오름), 보급 상자(두 배 화력·폭풍 연사·귤 방패·귤 잔치 중 하나를 12초), 온천(체력 회복).
- **전체 랭킹**: 전장별 점수 상위권을 선택창, 결과 화면, 랜딩페이지에서 봅니다. 점수는 처치 10점, 생존 1초 2점, 클리어 500점입니다.

기획 의도와 수치는 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)에 있습니다.

## 개발

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (기본 http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm run preview  # 빌드 결과 미리 보기
```

- `/` 는 랜딩페이지, `/play.html` 이 게임입니다.
- 개발용 주소 (화면 확인과 회귀 점검용)
  - `/play.html?unlock` 전장과 후반 장비를 모두 연 상태
  - `/play.html?unlock&map=city` 전장 지정 (`farm`, `city`, `desert`, `candy`)
  - `/play.html#play` 선택창 건너뛰기
  - `/play.html#sim90` 자동 조준·연사로 90초를 미리 진행 (숫자 생략 시 20초). 결과가 문서 제목에 JSON으로 남습니다
  - `/play.html#retry` 재시작 뒤에도 UI가 남는지 점검

### 배포

`main` 브랜치에 푸시하면 Vercel이 자동으로 빌드해 배포합니다. Vite 프리셋 기본값(빌드 `npm run build`, 출력 `dist`)을 그대로 씁니다.

### 전체 랭킹 서버 연결

랭킹은 `api/scores.js`(Vercel 서버리스 함수)가 Upstash Redis에 저장합니다. 연결 전에는 API가 503을 돌려주고, 게임은 "랭킹 서버에 연결할 수 없습니다"라고 표시한 채 기록을 기기에만 저장합니다.

1. Vercel 대시보드에서 프로젝트 → **Storage** → **Create Database** → **Upstash for Redis**(무료 요금제 가능)를 만들어 이 프로젝트에 연결합니다.
2. 환경 변수 `KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 추가됩니다. (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 이름도 인식합니다.)
3. 다시 배포하면 랭킹이 동작합니다.

기록은 클라이언트가 보내는 값이라 완전한 부정 방지는 되지 않습니다. 서버는 초당 처치 수 상한 같은 기본 검증만 합니다. 로컬 개발 서버(`npm run dev`)에는 `/api`가 없으므로 랭킹은 배포 환경이나 `vercel dev`에서만 동작합니다.

```

play.html             게임 (선택창, HUD, 레벨업 화면의 DOM)
src/
  main.js             게임 진입점. 선택창 ↔ 전장 전환, 프레임 루프
  select.js           캐릭터 선택창
  game.js             전장: 입력, 이동·돌진·점프, 좀비 떼와 보스, 무기, 레벨업, HUD
  world.js            전장 만들기: 지면, 지형지물, 고지대, 점프대, 소품, 하늘과 원경, 날리는 입자, 충돌 상자
  audio.js            효과음 (Web Audio 합성, 외부 파일 없음)
  upgrades.js         전투 수치, 레벨업 강화 목록, 합성 조합
  maps.js             전장 6곳의 색·조명·소품·지형지물·보스·좀비 정의
  save.js             계정(닉네임), 프로필, 진행도(클리어·기록), 설정 저장 (localStorage)
  rank.js             전체 랭킹 API 호출과 목록 표시
  kit.js              로우폴리 조립 키트, 조명, 모델 굽기(bake)
  models/
    capy.js           카피바라와 등에 실린 무기
    riders.js         라이더 동물 8종(특성 포함)과 악세사리
    zombies.js        좀비 조립 (맵별 장식 포함)
  landing.js/.css     랜딩페이지의 3D 미리보기와 스타일
  style.css           게임 UI 스타일
api/
  scores.js           전체 랭킹 서버리스 함수 (Upstash Redis)
docs/
  GAME_DESIGN.md      재미·완성도 기획서와 구현 상태
concepts/
  style-sheet.html    초기 그래픽 시안 4종 (A 로우폴리를 채택)
```

### 그래픽 방식

채택한 양식은 **로우폴리 플랫 셰이딩**입니다. 텍스처와 외부 모델 파일 없이, `kit.js`의 구·상자·원기둥·원뿔 프리미티브에 단색 머티리얼을 입혀 코드로 조립합니다.

좀비 떼는 수백 마리를 그려야 하므로, 조립한 좀비 모델을 정점 색을 가진 지오메트리 하나로 굽고(`bake`) 종류마다 `InstancedMesh` 하나로 그립니다. 맵 소품과 고지대도 한 덩어리로 구워 드로우콜 한 번에 그립니다.

### 내용 추가하기

- **합성 추가**: `src/upgrades.js`의 `FUSIONS`에 재료(`need`)와 효과(`apply`)를 추가합니다.
- **강화 추가**: `src/upgrades.js`의 `UPGRADES`에 항목을 추가합니다. `available(ctx)` 함수를 달면 해금 조건을 걸 수 있습니다 (`ctx.cleared`는 클리어한 전장 수).
- **전장 추가**: `src/maps.js`의 `MAPS`에 색, 소품 목록, 조명, 좀비 6종, 보스, 지형지물을 놓는 `build()`를 추가합니다. 랭킹을 받으려면 `api/scores.js`의 `MAPS`에도 id를 추가합니다. 새 좀비 장식은 `src/models/zombies.js`의 `acc` 분기에 추가합니다.
- **라이더·악세사리 추가**: `src/models/riders.js`의 `RIDERS`, `HATS`, `FACES`, `NECKS`에 추가하면 선택창에 자동으로 나타납니다.

## 아직 없는 것

- 배경 음악
- 메타 성장(영구 강화, 도전 과제), 협동 멀티플레이
- 데스크톱 빌드와 스팀 연동, 게임패드 지원
- 터치 기기용 로켓·스킬 버튼
- 난이도와 수치 밸런스 조정 (자동 진행으로만 점검했고, 사람 손으로 한 플레이테스트는 아직 부족합니다)
