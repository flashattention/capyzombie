# 카피좀비

세상 느긋한 카피바라 등에 올라탄 작은 동물이 되어, 1인칭으로 게틀링건과 로켓을 쏘며 몰려드는 좀비 떼를 물리치는 3D 웹 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

> 현재 프로토타입 단계입니다. 아래 "아직 없는 것"을 참고하세요.

## 플레이 방법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 (시선 기준) |
| 마우스 | 조준 |
| 좌클릭 | 게틀링건 연사 |
| 우클릭 (또는 `Shift`) | 돌진. 스태미나를 쓰며 좀비를 들이받아 날려 버립니다 |
| `Q` | 로켓 포드 |
| `E` | 발 구르기. 주변 좀비를 날려 버립니다 |
| `R` | 궁극기 귤 폭격. 좀비 40마리를 처치하면 충전됩니다 |
| `Space` | 점프. 언덕 위로 올라갈 수 있고, 높이 떨어지면 착지 충격파가 납니다 |
| `V` | 1인칭 ↔ 3인칭 전환 |
| `1` `2` `3` | 레벨업 강화 선택 |
| `Esc` | 마우스 풀기 (일시정지) |

화면을 클릭하면 마우스가 잠기고 조준이 시작됩니다. 터치 기기에서는 화면 왼쪽을 끌어 이동하고 오른쪽을 끌어 조준·사격하지만, 돌진 버튼과 Q·E·R 스킬 버튼은 아직 없습니다.

## 게임 구성

- **캐릭터 선택**: 라이더 동물 5종(오리, 개구리, 고양이, 강아지, 햄스터)을 고르고, 모자·얼굴·목 악세사리로 꾸미고, 이름을 지어 줍니다. 선택은 브라우저에 저장됩니다.
- **전장 4곳**: 맵마다 색과 소품, 등장하는 좀비 3종(기본·러너·탱커)이 다릅니다.

  | 전장 | 기본 | 러너 | 탱커 |
  |---|---|---|---|
  | 유자 농장 | 농부 좀비 | 꼬마 좀비 | 호박머리 |
  | 네온 도심 | 회사원 좀비 | 배달 러너 | 공사장 반장 |
  | 사막 유적 | 미라 좀비 | 카우보이 좀비 | 선인장 좀비 |
  | 캔디 놀이공원 | 파티모자 좀비 | 토끼 머리띠 | 풍선껌 뚱보 |

- **레벨업**: 좀비가 떨어뜨린 귤을 모으면 레벨이 오르고, 강화 카드 3장 중 하나를 고릅니다. 게틀링건·로켓 포드·카피바라 강화 12종이 있습니다.
- **고지대**: 점프로 1~2단 언덕에 오를 수 있습니다. 좀비도 잠시 버둥대다 기어오릅니다.

## 개발

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (기본 http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm run preview  # 빌드 결과 미리 보기
```

- `/` 는 랜딩페이지, `/play.html` 이 게임입니다.
- 개발용 주소: `/play.html#play` 는 선택창을 건너뛰고, `/play.html#sim` 은 자동 조준·연사로 20초를 미리 진행한 상태에서 시작합니다. 화면 확인과 회귀 점검에 씁니다.

### 배포

`main` 브랜치에 푸시하면 Vercel이 자동으로 빌드해 배포합니다. Vite 프리셋 기본값(빌드 `npm run build`, 출력 `dist`)을 그대로 씁니다.

## 코드 구조

```
index.html            랜딩페이지
play.html             게임 (선택창, HUD, 레벨업 화면의 DOM)
src/
  main.js             게임 진입점. 선택창 ↔ 전장 전환, 프레임 루프
  select.js           캐릭터 선택창
  game.js             전장: 입력, 이동·돌진·점프, 좀비 떼, 무기, 레벨업, HUD
  upgrades.js         전투 수치와 레벨업 강화 목록
  maps.js             전장 4곳의 색·소품·좀비 정의
  save.js             프로필 저장 (localStorage)
  kit.js              로우폴리 조립 키트, 조명, 모델 굽기(bake)
  models/
    capy.js           카피바라와 등에 실린 무기
    riders.js         라이더 동물 5종과 악세사리
    zombies.js        좀비 조립 (맵별 장식 포함)
  landing.js/.css     랜딩페이지의 3D 미리보기와 스타일
  style.css           게임 UI 스타일
concepts/
  style-sheet.html    초기 그래픽 시안 4종 (A 로우폴리를 채택)
```

### 그래픽 방식

채택한 양식은 **로우폴리 플랫 셰이딩**입니다. 텍스처와 외부 모델 파일 없이, `kit.js`의 구·상자·원기둥·원뿔 프리미티브에 단색 머티리얼을 입혀 코드로 조립합니다.

좀비 떼는 수백 마리를 그려야 하므로, 조립한 좀비 모델을 정점 색을 가진 지오메트리 하나로 굽고(`bake`) 종류마다 `InstancedMesh` 하나로 그립니다. 맵 소품과 고지대도 한 덩어리로 구워 드로우콜 한 번에 그립니다.

### 내용 추가하기

- **강화 추가**: `src/upgrades.js`의 `UPGRADES`에 항목을 추가합니다. `available(levels)` 함수를 달면 해금 조건을 걸 수 있습니다.
- **전장 추가**: `src/maps.js`의 `MAPS`에 색, 소품 목록, 좀비 3종을 추가합니다. 새 좀비 장식은 `src/models/zombies.js`의 `acc` 분기에 추가합니다.
- **라이더·악세사리 추가**: `src/models/riders.js`의 `RIDERS`, `HATS`, `FACES`, `NECKS`에 추가하면 선택창에 자동으로 나타납니다.
